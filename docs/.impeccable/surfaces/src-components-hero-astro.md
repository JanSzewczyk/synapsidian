# Landing hero

Scope: the hero of the docs landing (`src/content/docs/index.mdx`, `src/components/Hero.astro`). Mode: Persuade. Audience: Claude Code users and Obsidian users, equally. Action: install the core (commands with copy) or Get started. Proof: real skill names, commands, note paths; example content is neutral and illustrative. Constraint: Starlight splash template, site fonts, clay accent (#D97757) site-wide.

## Direction contract

THESIS: A session becomes notes, shown as the vault's own history. Refuses the copied SDD terminal-with-status-pills split.
OWN-WORLD: Near-black (dark) or white (light) ground, Poppins headline, JetBrains Mono for history and notes; a vertical commit rail with hollow grey dots and one filled clay dot; note cards in a full hairline border with a clay path label, grey frontmatter line and clay [[links]]. The brain mark in clay.
STORY: The visitor reads one line on what Synapsidian is, sees a day's commits (morning, capture, task, save, evening) each named after its skill, sees the newest save open onto the decision and daily note it wrote, then installs.
FIRST VIEWPORT: Left column: H1, tagline, Get started (clay) + secondary actions, install box with copy. Right column (~30rem): commit rail, newest-first; the `save` commit expanded with two note cards. On narrow screens the rail stacks under the copy.
FORM: Commit trail, position 7 of 7 on the ranked list, seed:94d8d1117228650a. Signature: on load the rail writes itself oldest to newest, then the save commit opens and its notes slide in; reduced motion shows the end state.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
