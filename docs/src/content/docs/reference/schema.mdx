The core's `schema/types.yaml`, field by field. A `*` marks a required field. Add-ons add types and fields: see [synapsidian-work](/synapsidian/extensions/work/) and [synapsidian-projects](/synapsidian/extensions/projects/).

## Every note

| Field | Kind |
| --- | --- |
| `type`* | text |
| `created`* | date |
| `summary`* | text; optional where a type says so |
| `tags` | list |
| `aliases` | list |

| Field | Kind | Values |

Body sections: `## Who I am`, `## Current focus`, `## How I work`, and `## Rules`, which is yours.

## Kinds

| Kind | Stored as |
| --- | --- |
| text | a string |
| date | `YYYY-MM-DD` |
| link | `"[[Note title]]"` |
| links | a list of links |
| list | a list of strings |
| number | a number |
